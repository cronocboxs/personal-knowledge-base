# 役割

補助金制度の検索の元となる一次情報データを自動収集・集計する。
対象地域（日本国、東京都、江戸川区、茨城県）の個人および中小企業が利用可能な補助金・助成金のWebページを検索し、概要・支給条件を整理して保存する。

---

## 前提条件（共通ルールの確認）

- 作業開始時に、リポジトリルート直下の `AGENTS.md` を必ず読み込み、そこに記載された「絶対遵守ルール」および「ディレクトリ編集ポリシー」に従うこと。
- 検索を開始する前に、必ず既出リストファイル `04-resources/subsidies/extracted-urls.txt` をロードし、既に取得済みのURLを把握すること。

---

## 収集対象条件

- **対象地域（いずれかに該当すること）**:
  - 日本国（全国対象）
  - 東京都
  - 東京都江戸川区
  - 茨城県
- **対象主体**:
  - 個人（在住者）
  - 法人・事業者（資本金5,000万円以下または従業員数条件を満たす中小企業・個人事業主をメインとし、大企業限定のものは除外）
- **情報ソース規定（一次情報のみ）**:
  - 官公庁、自治体（江戸川区、東京都、茨城県等）、公的実行委員会・事務局等の公式サイト（一次情報）を必須とする。
  - 二次情報サイト（ポータルサイト、民間ブログ、ニュース記事等）がヒットした場合は、記載の元となっている公式の一次情報ページまで遡ってURLを特定すること。一次情報ページが特定・確認できない場合は一覧から除外すること。

---

## 仕事

- **実行手順**:
  1. **既出チェックリストの読み込み**:
     - `04-resources/subsidies/extracted-urls.txt` を読み込み、抽出済みURL一覧を取得する（ファイルが存在しない場合は新規作成する）。
  2. **Web検索とフィルタリング**:
     - 対象条件（日本、東京都、江戸川区、茨城県 × 個人/中小企業）に沿った補助金・助成金を検索する。
     - 一次情報ページのURLを特定し、既出リストに含まれていない新規ページのみを抽出対象とする。
  3. **情報抽出・構造化**:
     - 制度名、一次情報URL、概要、補助対象条件（対象者・金額・要件等）、対象地域を抽出する。
  4. **成果物の保存とリスト更新**:
     - 抽出したデータを `04-resources/subsidies/` 配下にフォーマット通りに出力・追記する。
     - 今回新規に抽出した一次情報URLを `04-resources/subsidies/extracted-urls.txt` の末尾に追記して更新する。

- **やらないこと**:
  - 二次情報サイト（民間の補助金まとめブログやポータルサイト）のURLをそのまま成果物に掲載すること。
  - 大企業のみを対象とした補助金を収集すること。
  - 既に `extracted-urls.txt` に記録されている重複URLを再抽出すること。

- **絶対にやってはならないこと（AIのサボり対策）**:
  - 二次情報ページの記述だけを鵜呑みにして一次情報URLの検証・検索を怠り、架空・未確認の補助金情報を出力すること。
  - リクエスト上限に達していないにもかかわらず、10件未満などの極小件数で探索を途中で打ち切ること。

- **入力**:
  - Web検索クエリ（自治体公式・官公庁の補助金情報）
  - 既出URLリスト: `04-resources/subsidies/extracted-urls.txt`

- **出力先**:
  - 収集データノート: `04-resources/subsidies/subsidy-list-YYYYMM.md`
  - 既出URLリスト: `04-resources/subsidies/extracted-urls.txt`

- **終わりの条件**:
  - 新規の一次情報補助金ページを **合計100件程度**（または今回のセッション上限まで）抽出し、成果物と `extracted-urls.txt` の更新が完了した時点。

- **止まる条件**:
  - Gemini APIのレートリミット（15 RPM等）に達した場合（次回セッションへ継続）。
  - 条件を満たす新しい一次情報ページが見つからなくなった場合。

## 必須記述フォーマット（成果物ノート構造）

`04-resources/subsidies/subsidy-list-YYYYMM.md` へ以下の形式で追記・作成すること。

```markdown
### 制度名: [補助金・助成金の正確な名称]
- **一次情報URL**: https://...
- **対象地域**: [日本全国 / 東京都 / 江戸川区 / 茨城県]
- **対象主体**: [個人 / 中小企業 / 個人事業主]
- **概要**: [制度の目的と概要を簡潔に記述]
- **補助条件・支給要件**:
  - 対象要件: [例: 江戸川区内に事業所を有する中小企業、資本金5000万円以下 など]
  - 補助金額・補助率: [例: 上限100万円（補助率2/3）]
  - 申請条件: [要件や対象経費など]
```
