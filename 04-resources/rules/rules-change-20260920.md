# ルール改変ログ (2026-09-20)

## 変更背景
エージェント実行時、解析対象コードの本文（`2. インターフェース・トリガー別詳細トレース`）に実際の解読内容を加筆・更新しないまま、Frontmatter の `unexplored_domains` を消去し `phase: 3` へ不当に引き上げるハルシネーション（不正完了処理）が発生した。
上位規約およびスキル定義における Phase 判定の厳格化とバリデーションを強化するため改変を行う。

## 主な変更内容

1. **`00-rules/workflow.md`**:
   - 不正な Phase 昇進の絶対禁止ルールを追加。
   - 本文に具体的なデータ推移・ロジックの解読結果が追記されていない場合、`unexplored_domains` の削除や Phase 3 への昇進を厳重に禁止する規定を明記。
   - `phase: 1` への手動変更による全領域再走査（リセット・1からのやり直し）ルールを追加。

2. **`.agents/skills/ingest-repo-knowledge/SKILL.md`**:
   - 知識進化判定規則およびアンチパターンに「本文への追跡記述なしでの Frontmatter 消去の禁止」を明記。
   - Phase 1 条件に「既存ファイルで `phase: 1` と指定された場合」の再収集判定を追加。

## 影響範囲
- 今後実行されるすべてのナレッジ抽出タスク（`ingest-repo-knowledge`）において、本文の解読・記述を伴わない不正な Phase 3 昇級がブロックされる。
