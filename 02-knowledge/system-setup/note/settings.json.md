# ⚙️ settings.json - アプリケーション設定値ストア

## 🧠 役割と目的
`settings.json`は、本プロジェクトの動作に必要な、実行時の具体的な設定値や環境パラメータをJSON形式で保存するための専用ファイルである。これは、コードの構造的な定義（`config.py`）とは異なり、外部から変更される可能性の高い、実行環境に強く依存する設定を管理するために存在する。

## 🛠️ 保持されている設定の種類
本ファイルが具体的にどのような値を保持しているかによりますが、一般的に以下のような設定が行われることが想定されます。

1.  **API認証情報プレースホルダ**: 利用する外部APIのキーやトークン（ただし、本処理では既に`01-private`配下に独立している可能性が高い）。
2.  **デフォルト動作パラメータ**: LLM呼び出し時のデフォルトの温度(temperature)、最大トークン数(max_tokens)、または特定のレイテンシ制限などの調整パラメータ。
3.  **環境スイッチ**: 開発/ステージング/本番など、実行すべき環境を切り替えるフラグ。

## 🧩 `00-rules/formatting.md`との関連性
`config.py`が*どの*設定ファイルを読み込むかを定義する「ロジック」を提供するのに対し、`settings.json`自身は*具体的な*設定値の「データ」を提供する役割を果たします。この両者を組み合わせることで、**動的で柔軟な環境管理**が可能となります。

## ⚠️ 重要な留意点
このファイルの内容がシステム動作の前提条件となるため、本ファイルを直接編集する際は、必ずバージョン管理システム（Git）でのコミットと同期、そして`config.py`による読み込みロジックを経由することが必須です。
