# [server_config] config.py - Configuration Management

## 概要
`config.py` は、アプリケーション全体の重要な設定値を管理するための単一のソースです。環境変数、外部設定ファイル（`settings.json`）、および地域的な秘密情報（例: Gemini API Key）の取得ロジックを一元化しています。

**主要機能:**
*   **パス定義**: プロジェクトルート、各種設定ファイル、知識ベースのパスを定義し、アプリケーションの他のモジュールとの依存関係の基盤を提供します。
*   **設定ロード**: ローカルの`settings.json`が存在すればそれを読み込み、なければデフォルト値で作成します。
*   **秘密情報管理**: Gemini API Keyなどの機密情報（Credential）を、`01-private/`ディレクトリ内を検索して取得するヘルパー関数を提供します。

**技術的ポイント:**
このファイルは、永続的な設定（JSON）と一時的なハードコードされたデフォルト値の組み合わせにより、高い柔軟性と安全な初期状態保証を両立させています。

**関連ファイル**: `scripts/server/settings.json`, `scripts/server/settings.py` (仮定), `01-private/` 内の認証情報ファイル。
