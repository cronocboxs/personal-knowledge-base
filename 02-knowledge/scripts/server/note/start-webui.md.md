# scripts/server/start-webui.md (Note)

## 1. 目的と役割
`start-webui.md` は、開発者やユーザーが `scripts/server/start-webui.py` をスムーズにセットアップし、WebUIの機能仕様を理解するための解説ドキュメントです。

## 2. 構成と詳細
- **インストール手順**: `python3 -m pip install streamlit` 等のコマンド説明。
- **仕様**: 04-resources へのデータ保存、サブディレクトリ指定、一次データ保存からAI自動昇華パイプラインへの連携フロー。
