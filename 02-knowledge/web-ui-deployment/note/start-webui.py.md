# 🚀 start-webui.py - Webインターフェース起動スクリプト

## 🧠 役割と目的
このスクリプトは、本システム全体をローカルのWebブラウザ上で視覚的に動作検証し、ユーザーフレンドリーなインターフェースを提供することを目的としています。内部的には`streamlit`ライブラリに依存し、複雑なバックエンドのロジック（RAG検索、LLM呼び出し）を、手軽に操作できるWebインターフェースの裏側でラッピング（Wrapper）する役割を果たします。

## 🛠️ 主要機能とロジック詳細

### 1. Streamlit環境依存
- Streamlit特有のUI要素（サイドバー、`st.write`、`st.button`など）を用いて、ユーザーへの操作ガイドや入力フォームを作成しています。
- 実行の前提として、開発環境に`streamlit`がインストールされ、Webサーバーとしてローカルで起動することが求められます。

### 2. ユーザーフロー制御
スクリプトの実行フローは以下の構造を持っています:
1. **初期表示**: システムのオーバービューや、どの機能（チャット、knowledge baseなど）から始めるべきかというガイダンスを表示する。
2. **入力受付**: ユーザーからの自然言語クエリを受け取る。
3. **バックエンド呼び出し**: 受信したクエリをコア機能（通常は知識検索、`rag_service.py`など）に渡すパイプラインを想定した処理を実行します。
4. **結果表示**: 検索結果やLLMの応答をStreamlitの表示メカニズムを通じてレンダリングし、ユーザーに可視化します。

### 3. システムの結合点
このファイルは、`llm_client.py`や`rag_service.py`といった重要な内部ロジックを直接呼び出しているわけではなく、これらのサービスを**利用するクライアントの窓口**として機能します。システムの利用体験(UX)と初期のデモ環境を提供するための、最外層のレイヤーであると言えます。

## 🚦 留意点
これは単なる起動スクリプトであるため、ビジネスロジック自体は含んでおらず、システム全体のエントリーポイントとしての役割に特化しています。実際にLLMコールや知識検索を行う部分は、このスクリプトから呼び出される他のモジュールに委任されています。
