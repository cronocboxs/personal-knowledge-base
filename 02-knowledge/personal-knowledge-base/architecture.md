# personal-knowledge-base アーキテクチャ・ソースコード詳細解析 (`architecture.md`)

## 1. ディレクトリ構造・責務
当リポジトリは、AIエージェントとの協調運用に最適化された明確なディレクトリ構造（ライフサイクル・フロー規約に基づく）を採用しています。

| ディレクトリ | 役割 | 編集ポリシー |
| :--- | :--- | :--- |
| `00-rules/` | システム規約・フォーマット定義 | 参照専用（規約集） |
| `01-private/` | 個人情報・秘密情報保管場所 | 最高機密（`.gitignore` 対象） |
| `02-knowledge/` | 体系化された知見・概念メモ | AIエージェントが `04-resources/` から書き起こし |
| `03-output/` | 生成物・ドラフト・記事・コード | 成果物の配置場所 |
| `04-resources/` | 一次情報原本・Web素材・Gitリポジトリのクローン | 書き換え・直接削除禁止（読み取り専用） |
| `05-todo/` | タスク・プロジェクト管理 | タスク追加・ステータス更新 |
| `06-storage/` | 大容量ファイル・バイナリ | `.gitignore` 対象（外部同期前提） |
| `99-trash/` | 一時廃棄場所 | 直接削除（`rm`）禁止の退避先 |
| `scripts/` | 自動化・メンテナンス・同期スクリプト | 整理・検証スクリプトの配置 |
| `.agents/skills/` | エージェント手順書・スキル定義 | エージェント用タスク定義 |

## 2. コアモジュール・スクリプトの詳細解説
変更頻度が高くシステムの中核をなす `scripts/` 配下の自動化スクリプトの具体的な実装と責務を解説します。

### ① 構造検証スクリプト (`scripts/check-structure.sh`)
- **責務**: リポジトリのディレクトリ構造や必須ファイルの存在、不正なファイル配置がないかを検証するシェルスクリプト。
- **実装ロジック**: 
  指定されたルールや許可されたディレクトリパスに基づき、予期せぬファイルや機密ファイルが混入していないかをチェックします。

### ② Git履歴取得スクリプト (`scripts/fetch-git-log.sh`)
- **責務**: `04-resources/git-repository/` 配下のリポジトリに対して、クローン、ファイルツリー、コミット履歴、変更統計（`stats.txt`）を自動取得・更新する。
- **データフロー**: 
  1. 対象リポジトリの `clone/` から最新の情報を参照。
  2. `git log`, `git status`, `tree` などのコマンドを実行し、`history/` 配下にメタデータ（`file-tree.txt`, `raw-git-log.txt`, `stats.txt` 等）として出力。

### ③ タスク実行スクリプト (`scripts/run-goose-task.sh`)
- **責務**: Gooseエージェントを用いて特定のタスクを自動実行するためのラッパースクリプト。

## 3. 設定・セキュリティ・品質管理
- **Gitleeks (`.gitleeks.toml`)**: リポジトリ全体でのシークレットやAPIキーのハードコードを検出し、情報漏洩を防ぎます。
- **Git Hooks (`.githooks/pre-commit`)**: コミット前に自動でバリデーションやセキュリティスキャンを実行し、不適切なコードの混入を防ぐ品質統制の要となっています。
