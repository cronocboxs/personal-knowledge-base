# パーソナルナレッジベース (personal-knowledge-base) アーキテクチャ概要

本ドキュメントは、`04-resources/git-repository/personal-knowledge-base/clone/main` 配下のソースコードおよびドキュメントを基に、パーソナルナレッジベースの全体アーキテクチャと設計思想を体系化したものです。

## 1. プロジェクトの目的と設計思想

- **AIエージェントと人間の協調**: AIエージェント（Claude, Goose等）と人間が共同でナレッジを蓄積・整理するための構造化されたリポジトリ。
- **厳格なディレクトリ分離**: 一次情報、規約、知見、成果物、プライベート情報を明確に分離し、誤った書き換えや情報漏洩を防止する。
- **ライフサイクル管理**: 情報の収集 → 知識化 → 成果物作成 → タスク管理という明確なフロー（`00-rules/workflow.md`）に沿った運用。

## 2. ディレクトリ構造と各層の役割

| ディレクトリ | 役割 | 編集ポリシー |
| :--- | :--- | :--- |
| `00-rules/` | システム規約・フォーマット定義 | **参照専用**（ユーザー指定時のみ更新） |
| `01-private/` | 個人情報・秘密情報 | **最高機密**: `.gitignore` 対象。外部送信禁止 |
| `02-knowledge/` | 体系化された知見・概念メモ | 新規作成・追記（`04-resources/`から書き起こす） |
| `03-output/` | 成果物・記事・コードのドラフト配置 | `02-knowledge/`の内容から生成 |
| `04-resources/` | 参照資料・Web素材・一次情報の原本 | **原本の非破壊**（書き換え禁止） |
| `05-todo/` | タスク・プロジェクト・ロードマップ | ステータス更新・タスク追加 |
| `06-storage/` | 大容量ファイル・バイナリ | `.gitignore` 対象 |
| `99-trash/` | 一時廃棄場所 | 直接削除禁止、退避用 |
| `scripts/` | 自動化・メンテナンススクリプト | 整理・更新・検証用スクリプトの配置・実行 |
