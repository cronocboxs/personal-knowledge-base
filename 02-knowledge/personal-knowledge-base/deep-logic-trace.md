# personal-knowledge-base 最深部ロジック・処理トレースナレッジ

本ドキュメントでは、`personal-knowledge-base` リポジトリにおけるメンテナンススクリプト群、構造チェックロジック、正規表現によるサニタイズ（秘匿・非推奨表現の排除）処理、および Git フック（`pre-commit`）による自律型安全機構の最深部仕様を記述する。

## 1. 構造・サニタイズチェックの最深部ロジック (`scripts/check-structure.sh`)
- **役割**: ナレッジベース全体のディレクトリ規約遵守、Git追跡設定の誤り、および文書内への機密情報・日付・実URL・人名の混入（情報リーク）を検出する。
- **最深部ロジック（Deep Logic Execution Flow）**:
  1. **Git管理・ignore設定検証**:
     - `git ls-files 01-private/` を実行し、`.gitkeep` 以外のファイルが誤ってステージング・追跡されていないかを厳格に検査。
     - `git check-ignore` を用い、`01-private/` および `03-output/` 配下の日付形式ディレクトリ（例: `03-output/2026-09-21`）が確実に Git の追跡除外（.gitignore）対象になっているか検証。
  2. **正規表現による機密・リークパターンマッチング**:
     - ターゲットディレクトリ（`02-knowledge`, `03-output`, `00-rules`, `.agents`）を走査。
     - `grep -E -n -r` により、以下の複合正規表現（`COMBINED_PATTERN`）に一致するテキストを抽出。
       - **日付パターン**: 西暦表記（`[12][0-9]{3}[-/.]?(0[1-9]|1[0-2])[-/.]?(0[1-9]|[12][0-9]|3[01])|[12][0-9]{3}年[0-1]?[0-9]月[0-3]?[0-9]日`）
       - **人名パターン**: 誤検知を防ぎつつ特定の敬称（氏、さん、君、ちゃん、Mr.等）を伴う人名表現。
       - **URLパターン**: `https?://` から始まる外部URLリンクの混入。
  3. **エラー集計と安全停止**:
     - 違反や未サニタイズ箇所が1件以上検出された場合は、該当行とファイル名を出力して `exit 1` により即座に処理を中断。全項目クリア時のみ `exit 0` で正常終了。

## 2. Git フックによる自動検証ループ (`.githooks/pre-commit`)
- **役割**: コミット実行時に自動介入し、人間の目視に頼らずコードやナレッジの安全性を担保する。
- **最深部ロジック**:
  1. `core.hooksPath` 設定により `.githooks` 配下のスクリプトを有効化。
  2. コミット直前に `scripts/check-structure.sh` をサブシェル経由で実行し、構造・サニタイズ違反をブロック。
  3. `gitleeks protect --staged -v` を呼び出し、ステージングされた差分に対して高速なシークレット（APIキー、パスワード、秘密鍵）検出スキャンを実施。
