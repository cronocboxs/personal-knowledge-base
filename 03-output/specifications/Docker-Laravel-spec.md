# Docker-Laravel 仕様書

本仕様書は、`Docker-Laravel` リポジトリの Git 履歴および変更履歴をもとに作成されたシステム構成・機能仕様のドキュメントです。

## 1. 概要
本プロジェクトは、Laravel アプリケーション開発および本番運用をスムーズに行うための Docker 環境コンテナ定義集です。Nginx、PHP-FPM、MySQL、Laravel Reverb（WebSocket対応）等の各種サービスを `docker-compose` により統一的に管理・構築します。

---

## 2. システム構成・コンテナ仕様

### 2.1. サービス構成
- **Webサーバー (Nginx)**: リバースプロキシおよび PHP-FPM / Reverb 連携、SSL 証明書対応。テンプレート設定（`default.conf.template`）を利用。
- **アプリケーション (PHP-FPM)**: Laravel 稼働環境。PHP 8.4 対応（初期の PHP 8.1 / 8.2 から段階的にバージョンアップ）、各種拡張モジュール（cron, procps, sqlite3 等）搭載。
- **データベース (MySQL)**: MySQL 8.4 対応（初期の MySQL 8.0 からバージョンアップ）。バージョンに応じたカスタム設定ファイル（`my57.cnf`, `my80.cnf`, `my84.cnf`）を完備し、マイグレーション時のトラブル等を抑制。
- **リアルタイム通信 (Reverb)**: Laravel Reverb 用のコンテナ・Dockerfile 構築および専用マニュアルを追加し、リアルタイム通信機能をサポート。
- **開発・補助ツール**: MailHog / Redis / Memcached / Ngrok などのサービス・ボリューム定義を追加。

---

## 3. 主要な変更・機能追加履歴

### 3.1. 近年のアップデート（最新機能・インフラ改善）
- **本番デプロイワークフローの追加**: GitHub Actions (`deploy.yml`) による自動デプロイ機能の構築および継続的な最適化（メモリ拡張、ビルド最適化、キャッシュ処理、コンポーザーコマンド調整、再起動・ネットワーク不整合防止策）。
- **証明書およびセキュリティ関連の整備**: SSL/TLS 証明書ファイル（`fullchain.pem`, `privkey.pem`, `localhost.pem` 等）の配置ディレクトリ整理と Nginx 設定のテンプレート化。
- **Laravel Reverb 対応**: WebSocket サーバー構築用 Dockerfile および手順マニュアルの追加。
- **コンテナランタイムのバージョンアップ**: PHP 8.4, Nginx, MySQL 8.4 へのメジャーバージョンアップ対応。
- **テスト用データベース環境の分離**: ユニットテスト用 MySQL データベースボリュームおよび設定の追加。

---

## 4. 運用・デプロイ仕様
- **ConoHa等での運用手順**: クラウドサーバー（ConoHa等）上での Docker 利用手順をまとめたドキュメント（`ConoHa.md`）を整備。
- **設定ファイルのベース管理**: 機密情報や環境依存の設定ファイルを直接リポジトリに含めず、`.base` サフィックス付きのテンプレートとして管理し、各環境で適用する設計を採用。
