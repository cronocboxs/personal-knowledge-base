# ファイル分類・配置判定規約 (Classification & Routing Rules)

AIエージェントが新たな情報・ファイル・テキストを入力された際、配置先のディレクトリを迷わず判定するための分類ルールです。

---

## 1. 自動判定フローチャート (Decision Tree)

情報を取得・入力されたら、上から順番に条件を判定し、最初に合致したディレクトリへ配置してください。

1. **機密・個人情報か？**
   * YES ➔ `01-private/`
2. **動画・PDF・音声・大容量バイナリか？**
   * YES ➔ `06-storage/`
3. **外部からのWebクリップ・他人の記事・未加工の一次資料・ログ・コード原本か？**
   * YES ➔ `04-resources/`
4. **自身に関する事実、または `04-resources/` から抽出・概念化した自分の知見ノートか？**
   * YES ➔ `02-knowledge/`
5. **ブログ記事・提出用レポート・コード成果物など、公開・出力用の完成品/推敲中ドラフトか？**
   * YES ➔ `03-output/`
6. **タスク・TODO・プロジェクト計画・進行中のロードマップか？**
   * YES ➔ `05-todo/`
7. **エージェント定義・プロンプト・コンテキスト構造か？**
   * **手順書・作業フロー指示** ➔ `.agents/skills/`
8. **PythonやBashなど、プログラム実行用のスクリプトか？**
   * **一時的・検証用の使い捨てコード** ➔ `tmp/` （ルート直下への直接生成は絶対厳禁）
   * **定型処理・本番運用の自動化コード** ➔ `scripts/`

---

## 2. ディレクトリ別 判定基準マトリクス

| ディレクトリ | 判定条件・含まれるファイル | AI編集権限 |
| -- | -- | -- |
| 01-private/ | パスワード、APIキー、個人識別情報、日記、非公開メモ | アクセス絶対禁止 |
| 06-storage/ | 動画(.mp4)、音声、大容量PDF、データセットアーカイブ(.zip) | 移動・配置のみ |
| 04-resources/ | 外部一次情報、Web取得データ、API RAWレスポンス、取得ログ、コード原本 | 新規配置のみ許可（既存原本の変更・編集は厳禁） |
| 02-knowledge/ | 04-resources/ から抽出・概念化した自分の知見ノート、仕様解析ノート | 新規作成・追記・更新 (head/note二層化) |
| 03-output/ | 公開用記事、提出用レポート、プログラム成果物など完成品/ドラフト | 新規作成・追記 |
| 05-todo/ | 個別プロジェクトのタスク指示書、ロードマップ | 更新・追記 |
| .agents/skills/ | AI手順書、エージェントタスク指示書（SKILL.md） | 参照・機能追加 |
| scripts/ | 恒久的な運用自動化コード（Bash / Python 等） | 実行・作成・保守 |
| tmp/ | 動作確認・検証用の一次使い捨てスクリプト・データ | 作成・自由消去（ルート直下への生成は厳禁） |

---

## 3. 判断が曖昧な場合のフォールバック

* 外部情報 vs 内部知見:
  * 外部から取得したデータはまず `04-resources/` に新規保存する。
  * それを分析・要約・概念化したノートは `02-knowledge/` に新規作成する。
* 一時スクリプトの配置場所:
  * AIが動作確認やデータ取得のために作成する一時コード・検証ファイルは、**必ず `tmp/` に配置**すること。
  * ルート直下（`/`）への直接作成は固く禁止する。
* **削除するか迷った場合**:
  * 原則として物理削除（`rm`）は行わず、必ず `99-trash/` へ移動すること。
