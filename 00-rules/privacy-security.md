# セキュリティ・プライバシー規約 (Privacy & Security Rules)

本リポジトリにおける機密情報保護および AI エージェントのアクセス境界に関する規約です。

---

## 1. エージェントのアクセス境界・編集制限

* **`01-private/` の絶対遮断**:
  * AI エージェントは `01-private/` 配下を**一切読み込んではならない**（`.gitignore` 登録必須）。
* **`04-resources/` の新規保存・編集制限**:
  * **新規配置のみ許可**: 外部取得データ（Webスクレイピング、API RAWレスポンス、取得ログ、外部リポジトリ等）の新規出力・配置のみ許可する。
  * **原本変更の厳禁 (Read-Only 原則)**: 既存ファイルの書き換え・編集・追記・直接削除は一切禁止する。
* **基本運用範囲**:
  * `04-resources/` を元に `02-knowledge/` へ知見を書き起こす。
  * `02-knowledge/` を元に `03-output/` で成果物を作成する。
  * 成果物内のバイナリファイルは `06-storage/` に配置し、`03-output/` からはリンクを張る。

---

## 2. 外部連携時のデータサニタイズ (マスキング)

* Web検索スクリプトや外部 API / LLM 等への送信データからは、以下の情報を自動で匿名化・伏字化すること。
  * 個人名・連絡先・アカウント情報
  * 絶対パス（ローカルディレクトリ構造）
  * 内部 IP アドレス・固有識別子

---

## 3. セキュリティチェックの自動化

* コミット前および定型バッチ処理内で `scripts/` 内の自動セキュリティ検証スクリプトを実行すること。
  * `.gitignore` の除外設定漏れ（`01-private/`, `06-storage/`）
  * 伏字化漏れおよび非公開データの混入チェック
